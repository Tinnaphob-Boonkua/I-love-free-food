# Lanes

Four agents, four disjoint file sets, one visual world.

| Lane | Brief | Owns | Demo step |
|------|-------|------|-----------|
| **A** Foundation | [A-foundation.md](./A-foundation.md) | `src/lib`, `ui`, `chrome`, layout, config | Unblocks everyone |
| **B** Arrival | [B-arrival.md](./B-arrival.md) | `/`, `/start` | 1 |
| **C** Studio | [C-studio.md](./C-studio.md) | `/space/[id]` | 2 and 3 |
| **D** Gift | [D-gift.md](./D-gift.md) | `/g/*`, `/booth` | 4 and 5 |

Each brief is standing instructions — an agent reads `AGENTS.md`, then its lane file, then works. No prompt needs to be pasted.

Stub pages already exist for every route, so no lane is blocked. Replace your own stubs; leave the others alone.

Ownership matrix and merge order: [`../INTEGRATION.md`](../INTEGRATION.md).
